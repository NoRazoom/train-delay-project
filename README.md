# train-delay-project
Анализ отклонения отправления и прибытия поездов от расписания.

Добро пожаловать в приложение, предоставляющее возможность проанализировать данные отклонений бельгийских пассажирских поездов от расписания на основе предоставления данных от компании Infrabel!

Для развертывания проекта на локальном ПК выполните нижеперечисленные команды:

Клонируйте проект:
>git clone https://github.com/NoRazoom/train-delay-project.git

Перейдите в нужную директорию:
>cd train-delay-project/train-delay

Запустите R в терминале:
>R

Установите зависимость renv сли ее нет:
>install.packages("renv")

Перезапустите R:
>q()

Запустите R в терминале:
>R

Установите зависимости проекта:
>renv::restore()

Если появится вопрос Do you want to proceed? [Y/n]
>Y

Выйдите из терминала R:
>q()

Создайте файл .env:
>nano .env

В нем пропишите ваши параметры соответственно с примером:
```text
DB_NAME=train-delays
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=postgres
```

Запустите файл выполнения автоматизированного анализа:
>Rscript main.R


**На этом все:) Успешного использования!**
